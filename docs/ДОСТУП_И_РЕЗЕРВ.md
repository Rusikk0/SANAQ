# Доступ только для своих + резервная копия + штрих-код с ценой

## 1. Ограничение доступа (не все по ссылке)

**Важно:** HTML-сайт на GitHub **публичный** — ссылку технически может открыть кто угодно.  
Но **работать в кассе** смогут только те, у кого есть:

1. **Код доступа к сайту** (в `js/config.js` → `SITE_ACCESS_CODE`)
2. **Аккаунт** (email + пароль в Supabase)
3. **Доступ к магазину** (админ добавил в «Пригласить кассира»)

### Настройки в `js/config.js`

```javascript
SITE_ACCESS_CODE: '095market',        // смените на свой секрет
ALLOW_PUBLIC_SIGNUP: false,          // нет саморегистрации
ALLOW_PUBLIC_STORE_CREATE: false,    // нельзя создать чужой магазин
```

### Как добавить сотрудника

1. Вы (админ) входите на сайт.
2. **Кассиры и смены** → **Пригласить кассира** → email, пароль, имя.
3. Сотруднику сообщаете: ссылку сайта + **код доступа** + email + пароль.

### В Supabase (рекомендуется)

**Authentication** → **Providers** → **Email** → отключить **Enable sign ups**  
(тогда регистрация с сайта не сработает даже при обходе интерфейса).

## 2. Штрих-код с названием и ценой

В карточке товара: превью и **Печать штрих-кода** показывают:

- название  
- **цену продажи**  
- штрих-код  

Цена берётся из поля «Цена продажи» — при смене цены обновите превью (поле обновляется автоматически).

---

## 3. Резервная копия

**Кассиры и смены** → вкладка **Резервная копия** (только админ).

| Действие | Описание |
|----------|----------|
| **Скачать резервную копию** | JSON со всеми товарами, продажами, клиентами, сменами, расходами |
| **Восстановить** | Загрузить JSON; включите «Заменить всё» для полного восстановления |

Храните файлы `backup_*.json` на флешке, в облаке или на другом диске.

Рекомендация: делать копию **раз в неделю** и перед крупными изменениями.

---

## 4. Обновление сайта на GitHub

После изменения `config.js` или `index.html` — снова загрузите файлы в репозиторий (папка `js/` и `index.html`).

**Не публикуйте** `SITE_ACCESS_CODE` в открытых чатах — только сотрудникам лично.
