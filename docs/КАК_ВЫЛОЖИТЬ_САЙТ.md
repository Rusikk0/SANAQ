# Как получить обычный сайт в интернете (без CMD)

После публикации вы заходите **по ссылке в браузере**, как на любой сайт:  
`https://ваш-логин.github.io/autozapchasti/`  
Командная строка нужна только **один раз** при загрузке файлов (или через сайт GitHub без CMD).

---

## Способ 1 — GitHub Pages (бесплатно, постоянная ссылка)

### 1. Регистрация на GitHub

Откройте [https://github.com](https://github.com) → **Sign up** → создайте аккаунт.

### 2. Новый репозиторий

1. Кнопка **+** → **New repository**
2. Имя, например: `autozapchasti`
3. **Public**
4. **Create repository**

### 3. Загрузить файлы (без CMD)

На странице пустого репозитория:

1. **uploading an existing file** (или «Add file» → Upload files)
2. Перетащите **всю папку** `095` с компьютера (или все файлы: `index.html`, папки `js`, `supabase`, `docs`)
3. **Обязательно** должен быть файл `js/config.js` с вашими ключами Supabase
4. **Commit changes**

### 4. Включить сайт

**Подробная пошаговая инструкция с картинками в тексте:**  
→ **[docs/ЧАСТЬ_4_ВКЛЮЧИТЬ_САЙТ.md](ЧАСТЬ_4_ВКЛЮЧИТЬ_САЙТ.md)** ← откройте этот файл

Кратко:

1. Репозиторий → **Settings** → слева **Pages**
2. **Source**: Deploy from a branch
3. **Branch**: `main` → папка **`/ (root)`** → **Save**
4. Подождите 2–5 минут → скопируйте ссылку «Your site is live at …»

```text
https://ВАШ-ЛОГИН.github.io/autozapchasti/
```

### 5. Настроить Supabase под этот адрес

1. [Supabase Dashboard](https://supabase.com/dashboard) → ваш проект
2. **Authentication** → **URL Configuration**
3. **Site URL**:

```text
https://ВАШ-ЛОГИН.github.io/autozapchasti/
```

4. **Redirect URLs** — добавьте ту же ссылку и без слэша в конце:

```text
https://ВАШ-ЛОГИН.github.io/autozapchasti/
https://ВАШ-ЛОГИН.github.io/autozapchasti
```

5. **Save**

### 6. Открыть сайт

В браузере вставьте вашу ссылку GitHub Pages → **Регистрация** или **Войти**.

## Способ 2 — Netlify (ещё проще, drag-and-drop)

1. Откройте [https://app.netlify.com/drop](https://app.netlify.com/drop)
2. Зарегистрируйтесь (можно через Google)
3. Перетащите папку `095` на страницу
4. Получите ссылку вида `https://random-name.netlify.app`
5. Эту ссылку укажите в Supabase (**Site URL** и **Redirect URLs**), как в шаге 5 выше

---

## Почему нельзя открывать файл с диска

| Способ | Работает с Supabase |
|--------|---------------------|
| Двойной щелчок по `index.html` | ❌ Нет |
| `python` в CMD | ✅ Да, но только пока CMD открыт |
| **GitHub Pages / Netlify** | ✅ **Да, всегда, как обычный сайт** |

---

## Если сайт на GitHub «не открывается»

1. Подождите 5 минут после включения Pages
2. Проверьте, что в репозитории есть `index.html` в **корне**, не в подпапке
3. Открывайте ссылку **из Settings → Pages**, не `localhost`
4. В Supabase указан **тот же** HTTPS-адрес

---

## Обновление сайта после изменений

Снова **Upload files** на GitHub (или заменить файлы) → через минуту сайт обновится.
